# 技术人职业成长研究项目

本项目是一个基于声明式多智能体架构的研究系统，用于深入研究技术人的职业成长路径与核心竞争力建设。

## 研究主题

**核心问题**：
1. 如何判断自己是否到了"架构师"阶段？
2. 技术人如何提升决策能力？
3. 10 年经验的人，真正值钱的是什么？
4. 为什么很多团队写不出好代码？（组织因素，而不是语言或个人能力）

**研究意义**：
帮助技术人理性认知职业发展阶段，识别能力短板，制定成长策略。帮助技术管理者理解如何培养团队、优化组织以提升工程能力。

## 系统架构

本系统采用三阶段流水线模式：

```
数据收集 → 分析 → 报告生成
```

### 智能体

- **00.orchestrator.md** - 编排器：协调三阶段流程
- **01.data_collector.md** - 数据收集器：从多个来源收集数据
- **02.analyzer.md** - 分析器：对数据进行深度分析
- **03.reporter.md** - 报告生成器：生成最终研究报告

### 数据流

```
references/          → 参考材料（研究概览、数据来源、分析方法等）
data/01.materials/   → 第一阶段输出：收集的原始数据
data/02.analysis/    → 第二阶段输出：分析结果
data/03.reports/     → 第三阶段输出：最终报告
```

## 如何使用

### 1. 启动研究

在 Claude Code 中执行：

```
请使用 agents/00.orchestrator.md 开始执行研究任务
```

编排器会自动：
- 读取所有参考材料
- 依次启动三个阶段的智能体
- 监控执行进度
- 处理异常

### 2. 查看结果

- **原始数据**：`data/01.materials/` - 收集到的各类数据
- **分析结果**：`data/02.analysis/` - 能力模型、对比分析、因果链分析、案例研究、实践建议
- **最终报告**：`data/03.reports/tech-career-growth-report.md` - 完整的研究报告

### 3. 调整和优化

如需调整研究方向或方法，可以修改：

- **调整数据收集策略**：修改 `agents/01.data_collector.md` 或 `references/data-sources.md`
- **调整分析方法**：修改 `agents/02.analyzer.md` 或 `references/analysis-methods.md`
- **调整报告格式**：修改 `agents/03.reporter.md` 或 `references/report-template.md`
- **添加领域知识**：在 `references/` 下添加新文件，并在相应智能体蓝图中引用

## 语言设置

- **智能体蓝图语言**：中文
- **报告输出语言**：中文

所有智能体蓝图使用中文编写，生成的最终报告也使用中文。

## 质量保障

系统内置多层质量保障：

1. **智能体自检**：每个智能体都有质量标准，执行过程中持续自检
2. **阶段验证**：下一阶段智能体会验证上一阶段的输出
3. **人工审查**：所有中间输出完全保留，可随时人工审查和干预
4. **数据驱动**：强调量化数据和案例支撑，避免空洞理论

## 设计原则

- **声明式而非命令式**：用自然语言描述"要达成什么"，而非"如何做"
- **数据驱动**：领域知识外化为独立的参考文件
- **透明可追溯**：所有中间输出完全保留，数据流清晰可见
- **质量内建**：质量标准嵌入智能体蓝图中
- **工作空间隔离**：每个智能体只在项目目录内工作，防止上下文污染

## 注意事项

1. **首次运行时间**：数据收集和分析可能需要较长时间，请耐心等待
2. **网络依赖**：数据收集阶段需要访问外部资源（技术博客、论文等）
3. **结果验证**：建议人工审查关键发现，确保准确性
4. **迭代优化**：可根据初次运行结果，调整智能体蓝图和参考材料

## 关键特性

- ✅ **可重复运行**：可多次执行，持续优化
- ✅ **可并行执行**：单个阶段内的任务可并行，提高效率
- ✅ **完全透明**：所有过程和数据可见
- ✅ **易于维护**：非程序员也可通过修改参考文件来调整行为
- ✅ **质量优先**：内置多层质量检查
