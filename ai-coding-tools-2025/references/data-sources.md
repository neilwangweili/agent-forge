# 数据源说明

## 概述

本研究使用多个数据源进行并行收集，然后去重合并，确保全面覆盖主流 AI 编程工具。

## 主要数据源

### 1. Product Hunt

**用途**：发现新兴和热门的 AI 编程工具

**搜索关键词**：
- AI coding
- AI programming
- code assistant
- AI developer tools

**收集重点**：
- 2024-2025 年发布的新工具
- 用户评分和反馈
- 产品描述和核心功能

---

### 2. GitHub Trending

**用途**：识别开源 AI 编程项目

**搜索策略**：
- 浏览 Trending 页面
- 搜索相关主题标签（AI, coding-assistant, copilot）
- 关注 Star 数和活跃度

**收集重点**：
- 开源工具的技术栈
- 社区活跃度
- 最新提交和功能更新

---

### 3. Hacker News

**用途**：获取技术社区的讨论和评价

**搜索关键词**：
- AI coding tools
- Copilot
- Claude Code
- Cursor

**收集重点**：
- 用户真实反馈
- 工具对比讨论
- 行业趋势观点

---

### 4. 技术博客和评测文章

**主要来源**：
- The Verge
- TechCrunch
- Ars Technica
- InfoQ
- 开发者博客

**收集重点**：
- 专业评测
- 功能对比
- 使用体验

---

### 5. 官方网站和文档

**用途**：获取权威的产品信息

**收集内容**：
- 产品定位和愿景
- 功能列表和技术架构
- 定价信息
- 最新动态和 Changelog

---

## 数据收集流程

1. **并行收集**：同时从 5 个数据源收集信息
2. **去重合并**：对收集到的工具列表进行去重（同一工具可能在多个来源出现）
3. **信息整合**：对于重复的工具，合并来自不同来源的信息
4. **时间范围**：重点关注 2024-2025 年的信息，但也包含重要的历史背景

## 数据质量要求

- **准确性**：信息来自官方或可信来源
- **时效性**：优先使用最新数据
- **完整性**：每个工具收集 200-500 字的结构化信息
- **可验证性**：记录信息来源，便于后续验证

## 特殊说明

如果某些数据源访问困难，可以用已知的公开信息代替，确保研究进度。
