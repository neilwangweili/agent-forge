# AI 编程工具市场格局研究（2024-2025）

## 项目简介

这是一个基于 **AgentForge 多智能体架构**的研究项目，旨在深入分析 2024-2025 年 AI 编程工具的市场格局。

通过声明式的智能体系统，本项目将自动完成数据收集、分析和报告生成，产出专业的市场研究报告。

---

## 研究目标

### 核心问题

1. **当前市场上主流的 AI 编程工具有哪些？**
2. **它们各自的技术特点和定位是什么？**
3. **市场呈现出什么样的竞争格局和趋势？**

### 研究意义

- 帮助开发者选择合适的 AI 编程工具
- 为技术决策者提供市场洞察
- 为投资者和创业者识别机会和趋势

### 研究范围

- **时间范围**：重点关注 2024-2025 年
- **工具数量**：10-15 个主流工具（质量优先）
- **分析深度**：深入分析，不只是信息罗列

---

## 系统架构

本项目采用**三阶段流水线架构**：

```
阶段一：数据收集 → 阶段二：分析 → 阶段三：报告生成
```

### 智能体组成

1. **主协调器** (`agents/00.orchestrator.md`)
   - 协调整个研究流程
   - 监督各阶段执行
   - 确保数据正确传递和质量达标

2. **数据收集智能体** (`agents/01.data_collector.md`)
   - 从多个数据源收集 AI 编程工具信息
   - 去重和整合数据
   - 输出结构化数据到 `data/01.materials/`

3. **分析智能体** (`agents/02.analyzer.md`)
   - 对收集的数据进行分类统计
   - 进行趋势分析、特征对比、市场格局分析
   - 输出分析结果到 `data/02.analysis/`

4. **报告生成智能体** (`agents/03.reporter.md`)
   - 整合分析结果
   - 撰写专业研究报告
   - 输出最终报告到 `data/03.reports/`

## 设计特点

### 1. 声明式架构

- 智能体蓝图使用自然语言描述"要达成什么"和"标准是什么"
- 运行时（Claude Code）智能理解意图并选择"如何做"
- 带来极高的灵活性和适应性

### 2. 数据驱动

- 领域知识外化为独立的参考文件
- 修改参考文件可改变系统行为，无需修改智能体蓝图
- 非程序员也能维护和演进系统

### 3. 透明可追溯

- 所有中间产出完整保留
- 数据流清晰可见
- 人类可在任何阶段检查、验证、干预

### 4. 质量内建

- 质量标准嵌入智能体蓝图
- AI 在执行过程中持续对照标准自检
- 多层智能体交叉验证

### 5. 工作空间隔离

- 每个智能体被严格限制在项目目录内工作
- 防止上下文污染
- 确保系统可复现和可并行运行

---

## 质量承诺

本研究项目特别强调：

1. **质量优先于数量**
   - 只收集 10-15 个工具，确保每个工具信息准确完整

2. **深入分析**
   - 不只是罗列信息
   - 分析"为什么"和"意味着什么"

3. **有洞察的报告**
   - 不只是数据堆砌
   - 提供深刻见解和预测
   - 参考 Gartner 分析报告或 ThoughtWorks 技术雷达的风格

## 调整和优化

### 如何调整数据收集策略

编辑 `agents/01.data_collector.md` 或 `references/data-sources.md`

### 如何调整分析方法

编辑 `agents/03.reporter.md` 或 `references/report-template.md`、`references/style-guide.md`

### 如何添加领域知识

在 `references/` 目录下添加新的参考文件，并在相应的智能体蓝图中引用

## 注意事项

1. **首次运行请从协调器开始**
   - 不要直接启动单个智能体
   - 使用 `agents/00.orchestrator.md` 确保流程完整

2. **工作空间隔离**
   - 所有智能体只在 `ai-coding-tools-2025/` 目录内工作
   - 不会读写此目录外的文件

3. **数据源访问**
   - 某些数据源可能需要网络访问
   - 如遇访问困难，智能体会使用已知的公开信息代替

4. **执行时间**
   - 完整执行可能需要一定时间（取决于数据收集的复杂度）
   - 请耐心等待各阶段完成

## 关于 AgentForge

本项目基于 **AgentForge** 多智能体架构生成。

AgentForge 是一个声明式的研究多智能体系统框架，通过自然语言定义智能体行为，利用文件系统作为数据总线，支持并行执行，完全透明可追溯。

核心设计模式：
- **Prompt-Defined Agent**：用 Markdown 定义智能体
- **Orchestrated Agent Pipeline**：流水线协调
- **Filesystem Data Bus**：文件系统数据传递
- **Parallel Instance Execution**：并行实例执行
- **Reference Data Configuration**：参考数据配置
