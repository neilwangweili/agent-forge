## 收集任务

根据 Orchestrator 分配的任务，收集以下主题之一的数据：

**搜索关键词**：
- "Gemini 3 coding capabilities"
- "Gemini 3 programming benchmark"
- "AI coding tools 2024 2025"
- "Vibe Coding"

- AI 编程工具（Cursor、Claude Code、GitHub Copilot）的最新能力

**输出文件**：`data/01.materials/01-gemini3-ai-coding.json`

### 任务 2："程序员失业论"的来源与论据

**搜索关键词**：
- "AI will replace programmers"
- "programmers jobs AI"
- "Jensen Huang coding"
- "Sam Altman software engineers"
- "Stack Overflow Developer Survey 2024"

**收集内容**：
- 科技领袖关于 AI 取代程序员的言论（完整上下文）

- 支持"失业论"的数据和论据
- 反对意见和质疑

**输出文件**：`data/01.materials/02-programmer-job-concerns.json`

### 任务 3：软件维护的本质与 AI 局限

**搜索关键词**：
- "software maintenance cost statistics"

- AI 在理解上下文、全局视野方面的局限

**输出文件**：`data/01.materials/03-software-maintenance-ai-limits.json`

### 任务 4：架构决策的不可替代性

**搜索关键词**：

## 输出格式

每个任务输出一个 JSON 文件，结构如下：

```json
{
  "topic": "主题名称",
  "collected_at": "收集时间",
  "summary": "主题摘要（100-200字）",
  "key_findings": [
    {
      "finding": "发现描述",
      "data": "支撑数据或引用",
      "source": "来源",
      "credibility": "官方数据/权威研究/行业共识/个人观点"
    }
  ],
  "cases": [
    {
      "title": "案例标题",
      "description": "案例描述",
      "source": "来源",
      "relevance": "与研究问题的关联"
    }
  ],
  "expert_opinions": [
    {
      "expert": "专家姓名/身份",
      "opinion": "观点内容",
      "context": "观点的上下文",
      "source": "来源"
    }
  ],
  "common_misconceptions": [
    {
      "misconception": "常见误区",
      "clarification": "澄清说明"
    }
  ]
}
```

## 质量标准

1. **数据准确**：确保数据来源可靠，标注可信度
2. **案例具体**：案例要具体、可验证，避免泛泛而谈
3. **观点平衡**：收集支持和反对的观点，保持客观
4. **时效性**：优先收集 2024-2025 年的信息
5. **篇幅控制**：每个主题 300-500 字的结构化信息

## 执行说明

1. 使用 WebSearch 工具搜索相关信息
2. 使用 WebFetch 工具获取具体页面内容
3. 提取关键信息并整理成 JSON 格式
4. 将结果写入指定的输出文件
