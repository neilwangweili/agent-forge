## 分析任务

### 任务 1：安装步骤简化分析

**输入**：`data/01.materials/installation-guide-raw.md`

**目标**：将官方安装指南转化为小白友好的操作指南

**分析要点**：

1. **步骤合并**
   - 识别可以合并的步骤
   - 去除非必要的技术细节
   - 保留核心操作

2. **语言简化**
   - 用通俗语言替代技术术语
   - 首次出现的术语需简要解释

3. **预期引导**
   - 每个步骤完成后用户应该看到什么
   - 用"你会看到..."的句式

4. **易错点标注**
   - 标注容易出错的地方
   - 用「注意」或「提示」格式

**输出文件**：`data/02.analysis/simplified-installation.md`

**输出格式**：
```markdown
# 简化后的安装步骤

## 准备工作

{需要提前准备的内容}

## 安装步骤

### 第一步：{步骤名称}

{具体操作描述}

你会看到：{预期结果}

> 注意：{易错点提醒，如有}

### 第二步：{步骤名称}

{继续...}

## 常见问题

{从 faq-and-tips.md 中提取相关内容}
```

### 任务 3：场景价值与深远意义分析

**输入**：
- `data/01.materials/project-overview.md`
- `data/01.materials/project-background.md`

**目标**：提炼 OpenClaw + 飞书的价值主张和深远意义

**分析内容**：

#### 3.1 使用场景（2-3 个）

为每个场景回答：
- 具体的使用场景是什么？
- 解决了什么问题？
- 比原来的方式好在哪里？

**示例场景**：
- 在飞书群里 @AI 让它帮你总结文档
- 私聊 AI 机器人随时问问题
- 团队共享一个 AI 助手，统一知识入口

#### 3.2 对比优势

与直接使用 Claude/ChatGPT 网页版相比：
- 使用便捷性
- 工作流整合
- 数据隐私
- 成本控制

#### 3.3 深远意义

三个层面的意义：

1. **从工具到入口**
   - 飞书不再只是聊天工具，而是 AI 入口
   - 改变人与 AI 的交互方式

2. **AI Agent 时代**
   - AI 从"对话框"走向"自主执行"
   - 普通人进入 AI Agent 时代的第一步

3. **开源与自主可控**
   - 数据留在本地
   - AI 民主化的体现

**输出文件**：`data/02.analysis/value-proposition.md`

**输出格式**：
```markdown

## 使用场景

{场景描述，具体、可感知}

### 场景二：{场景名称}

{场景描述}

### 场景三：{场景名称}

{场景描述}

## 对比优势

{与网页版 AI 的对比，突出 OpenClaw + 飞书的优势}

## 深远意义

### 从工具到入口

{阐述}

### AI Agent 时代的第一步

{阐述}

### 开源与自主可控

{阐述}
```

## 质量标准

### 简化程度
- [ ] 步骤数量合理（不超过 10 步）
- [ ] 每步只做一件事
- [ ] 无专业术语或已解释

### 可操作性
- [ ] 每个步骤都有明确的操作指令

- [ ] 假设读者不会写代码
- [ ] 假设读者会用电脑和飞书

- [ ] 场景具体可感
- [ ] 优势对比明确
- [ ] 意义阐述克制、有依据
