# 简化后的飞书对接步骤

## 准备工作

在开始之前，请确认以下几项：

1. **OpenClaw 已安装并运行**：完成安装指南中的所有步骤，确保 `openclaw-cn gateway status` 显示正在运行
2. **一个飞书账号**：你日常使用的飞书账号即可
3. **企业管理员权限**（或联系管理员）：创建企业自建应用需要管理员审批

> 注意：飞书对接分为两侧操作——先在飞书开放平台创建应用，再在 OpenClaw 侧配置连接。两侧都配好后才能正常工作。

---

## 飞书开放平台操作

### 第一步：登录飞书开放平台

用浏览器打开 [飞书开放平台](https://open.feishu.cn/app)，使用你的飞书账号登录。

你会看到：飞书开放平台的应用管理页面。

---

### 第二步：创建企业自建应用

点击页面上的 **"创建企业自建应用"** 按钮。

填写以下信息：
- **应用名称**：给你的 AI 助手起个名字，例如"AI 助手"
- **应用描述**：填写一句话说明，例如"基于 OpenClaw 的 AI 助手"
- **应用图标**：选一个你喜欢的图标

然后点击"创建"。

你会看到：页面跳转到应用详情页。

---

### 第三步：复制应用凭证

在应用详情页中，找到 **"凭证与基础信息"** 页面。

你需要复制两个信息并妥善保存：
- **App ID**：格式类似 `cli_xxx`
- **App Secret**：点击"显示"后复制

你会看到：两串字符，这就是 OpenClaw 连接飞书的"钥匙"。

> 注意：App Secret 相当于密码，不要分享给任何人。如果不慎泄露，立即在此页面点击"重置"。

---

### 第四步：一键导入应用权限

在左侧菜单找到 **"权限管理"** 页面，点击 **"批量导入"** 按钮。

将以下内容完整复制，粘贴到导入框中：

```json
{
  "scopes": {
    "tenant": [
      "aily:file:read",
      "aily:file:write",
      "application:application.app_message_stats.overview:readonly",
      "application:application:self_manage",
      "application:bot.menu:write",
      "contact:user.employee_id:readonly",
      "corehr:file:download",
      "event:ip_list",
      "im:chat.access_event.bot_p2p_chat:read",
      "im:chat.members:bot_access",
      "im:message",
      "im:message.group_at_msg:readonly",
      "im:message.p2p_msg:readonly",
      "im:message:readonly",
      "im:message:send_as_bot",
      "im:resource"
    ],
    "user": [
      "aily:file:read",
      "aily:file:write",
      "im:chat.access_event.bot_p2p_chat:read"
    ]
  }
}
```

点击"导入"后确认。

你会看到：权限列表中出现了一系列已勾选的权限项。

> 注意：这些权限是机器人正常工作所必需的——包括接收消息、发送消息、读取群聊信息等。缺少任何一项都可能导致机器人功能异常。

---

### 第五步：开启机器人能力

在左侧菜单找到 **"应用能力"**，点击进入 **"机器人"** 页面。

- 将机器人能力的开关**打开**
- 填写机器人名称（和你的应用名称保持一致即可）

你会看到：机器人能力显示为"已启用"状态。

---

### 第六步：配置事件订阅

在左侧菜单找到 **"事件订阅"** 页面。

1. 选择 **"使用长��接接收事件"**（WebSocket 模式）
2. 点击"添加事件"，搜索并添加 `im.message.receive_v1`（接收消息事件）

你会看到：事件列表中出现"接收消息 v1"的条目。

> 注意：这一步**必须在 OpenClaw 侧配置完成且网关已启动之后**才能保存成功。如果保存失败，请先完成下方"OpenClaw 配置"部分，再回来保存此页面。

---

### 第七步：发布应用

在左侧菜单找到 **"版本管理与发布"** 页面。

1. 点击"创建版本"
2. 填写版本号和更新说明（随意填写即可）
3. 点击"提交审核并发布"

你会看到：应用状态变为"审核中"或"已上线"。

> 注意：企业自建应用通常会自动通过审核。如果长时间未通过，请联系你的飞书企业管理员。

---

## OpenClaw 配置

### 第一步：添加飞书渠道

在终端输入以下命令：

```bash
openclaw-cn channels add
```

向导会出现交互式提示。

1. 选择 **Feishu**（飞书）
2. 粘贴你在第三步复制的 **App ID**
3. 粘贴你在第三步复制的 **App Secret**

你会看到：终端提示飞书渠道已添加成功。

---

### 第二步：重启网关

添加渠道后，需要重启网关让配置生效：

```bash
openclaw-cn gateway restart
```

你会看到：终端提示网关已重启。

> 注意：如果之前飞书开放平台的"事件订阅"页面保存失败，现在网关已启动，可以回去重新保存。

---

## 测试验证

### 第一步：在飞书中找到你的机器人

打开飞书，在通讯录或搜索栏中搜索你创建的机器人名称，点击进入对话。

### 第二步：发送一条测试消息

给机器人发送任意一条消息，例如"你好"。

你会看到：机器人回复一个**配对码**（一串数字或字母）。

### 第三步：批准配对

回到终端，输入以下命令（将 `<配对码>` 替换为你收到的那串码）：

```bash
openclaw-cn pairing approve feishu <配对码>
```

你会看到：终端提示配对已批准。

### 第四步：再次发送消息

回到飞书，再给机器人发送一条消息，例如"今天天气怎么样？"

**成功标志**：机器人正常回复了你的问题，而不是再次发送配对码。恭喜，飞书对接完成了。

---

## 常见问题

### 机器人发出配对码后，批准命令不起作用

请检查配对码是否完整复制。可以用以下命令查看待批准列表：

```bash
openclaw-cn pairing list feishu
```

### 机器人完全没有响应

按以下顺序排查：

1. 检查应用是否已在飞书开放平台上发布并审批通过
2. 检查事件订阅是否配置了 `im.message.receive_v1` 且使用"长连接"模式
3. 检查网关是否在运行：`openclaw-cn gateway status`
4. 查看实时日志寻找错误信息：`openclaw-cn logs --follow`

### 机器人在私聊正常，但在群里不响应

默认情况下，在群组中需要 **@机器人** 才会触发回复。确保你在消息中 @了机器人的名字。

### 提示"未建立长连接"

说明 App ID 或 App Secret 配置有误，或者网关没有启动。请依次检查：

1. 回到飞书开放平台，确认 App ID 和 App Secret 是否复制正确
2. 在终端运行 `openclaw-cn gateway status` 确认网关正在运行
