# 把电脑变成远程员工：OpenClaw + 飞书实战指南

## 开篇

想象一下：你正在外面吃饭，突然收到一条紧急消息，需要处理一份电脑上的文件。以前你只能说“等我回去”，现在你可以掏出手机，打开飞书，给 AI 助手发一条消息：“帮我把桌面上那份报告的第三章总结一下，发到工作群里。”几分钟后，事情就办完了。你的电脑在家里，但 AI 在替你干活。

这就是 OpenClaw 做的事情。它是一个开源项目，在 GitHub 上已经获得了超过 10 万颗 star。OpenClaw 运行在你的电脑上，通过飞书接收你的指令，然后在电脑上执行任务。它不只是一个聊天机器人，而是一个能够操作你电脑的 AI 代理。它可以读写文件、运行命令、浏览网页、处理数据。

OpenClaw 支持多种 AI 模型，包括 Claude、GPT、通义千问等。数据不经过第三方服务器，用多少付多少，完全掌握在自己手中。除了飞书，它还能对接Discord、Telegram 等工具，一个部署覆盖多个入口。这篇文章会一步步带你完成本地安装和飞书对接，让你拥有一个可以远程控制的 AI 助手。

## 它能做什么

在介绍安装步骤之前，先说说它能帮你做什么。

OpenClaw 的核心能力是：通过手机聊天工具，远程控制你电脑上的 AI 去执行任务。你人可以在任何地方，只要电脑开着、OpenClaw 在运行，你就能通过聊天工具指挥它干活。

拿飞书来举例子。

你在出差途中，客户突然要一份数据分析报告。你打开手机飞书，告诉 AI 助手：“打开桌面上的销售数据表格，按区域汇总第四季度的销售额，生成一份简报，发到我的工作邮箱。” AI 在你家里的电脑上打开文件、处理数据、生成报告、发送邮件。你在高铁上刷着手机，事情已经办完了。这在以前是不可能的。要么你得带着电脑，要么你得等回去再处理。

团队也可以共享同一台部署了 OpenClaw 的电脑。多个人可以同时通过飞书给 AI 下达指令，AI 会依次执行。比如运维团队可以共享一台服务器上的 OpenClaw，任何人都能通过飞书查询系统状态、执行常规操作，不用每个人都登录服务器。又比如一个小团队把 OpenClaw 部署在办公室的一台公共电脑上，大家都能让它帮忙处理文件、查资料、跑脚本。

处理紧急情况是它的另一个典型场景。周末晚上你在餐厅吃饭，收到告警说某个服务挂了，或者是让你紧急出一份方案、处理一份报告。你不用急着找电脑，掏出手机在飞书里和机器人说一句，AI 就能帮你解决问题。这种随时随地远程操控的能力，是 OpenClaw 区别于普通聊天机器人的地方。

## 本地安装指南

> 亦可参考官方文档：https://clawd.org.cn（因为国际版 OpenClaw 不支持飞书，所以笔者特地选择了国内版 OpenClaw 。）

### 准备工作

开始安装前，先确认以下几项：

1. 一台电脑，Mac、Windows 或 Linux 均可
2. 一个 AI 模型的 API Key。推荐使用 Anthropic 的 Claude API Key，这相当于 AI 的通行证，需要在 Anthropic 官网注册获取。也可以使用阿里千问 Qwen 的 API Key，阿里千问在注册的时候会送很多的免费token使用。
3. 网络连接，安装过程需要联网下载

> 注意：Windows 用户需要使用 PowerShell 执行安装命令，不要使用"命令提示符（CMD）"。

### 安装步骤

**1. 运行一键安装命令**

打开终端（Mac/Linux）或 PowerShell（Windows），复制以下命令并按回车执行。

Mac / Linux 用户：

```bash
curl -fsSL https://clawd.org.cn/install.sh | bash
```

Windows 用户：

```powershell
iwr -useb https://clawd.org.cn/install.ps1 | iex
```

这条命令会自动安装 OpenClaw的客户端。你会看到终端中出现一系列安装进度信息，最后提示安装完成。

> 注意：在安装改服务前，必须先安装最新版本的Node。安装过程可能需要几分钟，请耐心等待，不要中途关闭终端窗口。

**2. 验证安装是否成功**

在终端中输入：

```bash
openclaw-cn --version
```

你会看到一个版本号，例如 `v2026.1.31`。如果提示 `openclaw-cn: command not found`，请关闭终端，重新打开一个新的终端窗口再试。如果仍然不行，可能是系统找不到 OpenClaw 的安装路径，参考文末的常见问题解决。

**3. 运行设置向导**

输入以下命令，启动初始设置向导：

```bash
openclaw-cn onboard
```

你会看到终端中出现一系列选择题和输入框，向导会用交互式问答引导你完成配置。

**4. 选择"快速启动"模式**

向导的第一个问题会让你选择模式。选择"快速启动"（Quick Start），这个模式会自动设好大部分配置，你要填入的是关键信息。

**5. 填入 API Key**

向导会问你用哪个 AI 模型。选择"Anthropic API Key"，然后粘贴你提前准备好的 Claude API Key。

或者选择"Qwen Auth"，并在弹出的浏览器中登录 Qwen 账户。

> 注意：粘贴时终端可能不会显示你粘贴的内容，这是正常的安全行为，直接按回车确认即可。

**6. 完成向导并启动健康检查**

向导会自动完成剩余配置，最后执行一次健康检查。你会看到所有检查项目都显示绿色对勾或"OK"标识。

> 注意：如果健康检查出现红色叉号，不要紧张。记下错误信息，参考官方文档或在社区寻求帮助。

**7. 确认 OpenClaw 正在运行**

输入以下命令查看运行状态：

```bash
openclaw-cn gateway status
```

你会看到网关状态显示为"running"（运行中）。到这里，OpenClaw 已经在你的电脑上运行起来了。

### 常见问题

**提示 `openclaw-cn: command not found`**

这是最常见的问题，原因是系统找不到 OpenClaw 的安装路径。解决方法：在终端输入 `npm config get prefix`，记下返回的路径；然后打开你的 Shell 配置文件（Mac 用户通常是 `~/.zshrc`），在文件末尾添加一行：`export PATH="$PATH:刚才的路径/bin"`；保存文件，关闭终端，重新打开再试。

**提示 Node.js 版本过低**

OpenClaw 需要 Node.js v22.0.0 或更高版本。访问 Node.js 官网下载最新版本安装即可。

## 飞书对接指南

飞书对接分为两侧操作：先在飞书开放平台创建应用，再在 OpenClaw 侧配置连接。两侧都配好后才能正常工作。

### 飞书开放平台操作

**1. 登录飞书开放平台**

用浏览器打开 [飞书开放平台](https://open.feishu.cn/app)，使用飞书账号登录。你会看到应用管理页面。如果是第一次访问，需要先完成开发者身份认证。

**2. 创建企业自建应用**

点击"创建企业自建应用"按钮，填写应用名称（例如"AI 助手"）、应用描述（例如"基于 OpenClaw 的 AI 助手"）和图标，然后点击"创建"。页面会跳转到应用详情页。

> 注意：创建企业自建应用需要企业管理员权限。如果你不是管理员，请联系管理员协助创建或给你授权。

**3. 复制应用凭证**

在应用详情页的"凭证与基础信息"页面，复制并妥善保存 **App ID**（格式类似 `cli_xxx`）和 **App Secret**（点击"显示"后复制）。这两串字符是 OpenClaw 连接飞书的"钥匙"，后续配置时需要用到。

> 注意：App Secret 相当于密码，不要分享给任何人。如果不慎泄露，立即在此页面点击"重置"生成新的密钥。

**4. 导入应用权限**

在左侧菜单找到"权限管理"页面，点击"批量导入"，将官方提供的权限 JSON 完整粘贴到导入框中并确认。这些权限是机器人接收消息、发送消息和读取群聊信息所必需的。缺少任何一项都可能导致机器人功能异常。

~~~json
{
  "scopes": {
    "tenant": [
      "aily:file:read",
      "aily:file:write",
      "application:application.app_message_stats.overview:readonly",
      "application:application:self_manage",
      "application:bot.menu:write",
      "contact:user.employee_id:readonly",
      "corehr:file:download",
      "event:ip_list",
      "im:chat.access_event.bot_p2p_chat:read",
      "im:chat.members:bot_access",
      "im:message",
      "im:message.group_at_msg:readonly",
      "im:message.p2p_msg:readonly",
      "im:message:readonly",
      "im:message:send_as_bot",
      "im:resource"
    ],
    "user": [
      "aily:file:read",
      "aily:file:write",
      "im:chat.access_event.bot_p2p_chat:read"
    ]
  }
}
~~~

**5. 开启机器人能力并配置事件订阅**

在"应用能力"中打开机器人开关，填写机器人名称（和应用名称保持一致即可）。然后在"事件订阅"页面，选择"使用长连接接收事件"（WebSocket 模式），点击"添加事件"，搜索并添加 `im.message.receive_v1`（接收消息事件）。

> 注意：这一步的保存操作需要 OpenClaw 侧网关已启动。如果保存失败，先完成下方的 OpenClaw 配置，再回来保存。

**6. 发布应用**

在"版本管理与发布"页面，点击"创建版本"，填写版本号和更新说明，然后点击"提交审核并发布"。企业自建应用通常会自动通过审核。一般立刻就审核通过了。如果长时间未通过，请联系飞书企业管理员。

### OpenClaw 侧配置

回到终端，输入以下命令添加飞书渠道：

```bash
openclaw-cn channels add
```

按照提示选择 Feishu（飞书），依次粘贴你在第三步复制的 App ID 和 App Secret。终端会提示飞书渠道已添加成功。添加完成后，重启网关让配置生效：

```bash
openclaw-cn gateway restart
```

终端提示网关已重启后，如果之前飞书开放平台的"事件订阅"页面保存失败，现在可以回去重新保存了。

### 测试验证

在飞书中搜索你创建的机器人名称，点击进入对话，发送一条消息，例如"你好"。机器人会回复一个配对码（一串数字或字母）。回到终端，执行配对批准命令（将 `<配对码>` 替换为你收到的那串码）：

```bash
openclaw-cn pairing approve feishu <配对码>
```

终端提示配对已批准后，再次在飞书中给机器人发送一条消息，例如"今天天气怎么样？"。当机器人正常回复你的问题，而不是再次发送配对码时，说明飞书对接已经完成。

> 注意：如果机器人在私聊正常，但在群里不响应，是因为默认情况下在群组中需要 @机器人 才会触发回复。

## 意义

过去，使用电脑意味着你必须坐在电脑前面。OpenClaw 改变了这一点：电脑放在家里 24 小时运行，你只需要一部手机或平板，就能随时随地指挥它干活。这是人和电脑分离的开始。人不再被物理位置束缚，电脑从必须亲自操作的工具变成了可以远程指挥的助手。

这是一种角色转变。你不再是亲自干活的人，而是发号施令的那个。AI 成了你的员工，你说要什么结果，它自己想办法完成。以前会用电脑是技能，现在会指挥 AI才是。但门槛反而更低了：不用学命令行，不用懂编程，说清楚你想要什么就行。

一个人加上几个 AI，产出能力可以接近一个小团队。你可以在家里、公司各放一台电脑，都装上 OpenClaw，通过飞书统一调度。一台处理文档，一台跑数据，一台做搜索。你像指挥员工一样分配任务，只看最终结果。个体的边界被放大了，一个人能干的事变多了。

这也让平板替代电脑有了新的可能。不是平板本身变强了，而是它变成了指挥中心，真正的算力留在家里的电脑上。出门带个 iPad 就够了，AI 交付的文档、网页，在平板上看刚好。手机也能用，就是屏幕小看着费劲。家里那台电脑 24 小时开着，就是你的私有云。不用买服务器，不用租云主机，已有的设备就能胜任。

当然，随时能处理工作也意味着随时可能被工作找上门。这是解放还是束缚，取决于你怎么用。另外，本地部署意味着安全责任在你自己：API Key 要保管好，网络访问要控制，电脑别让人随便碰。

## 结语

如果你对以上内容感兴趣，不妨动手试试。部署 OpenClaw，是普通人进入 AI 时代的一小步。
