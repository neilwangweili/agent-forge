## 更名历程

OpenClaw 项目经历了三次命名变更，反映了开源项目在快速增长中面临的各种挑战：

### 1. Clawd / Clawdbot（2025年11月 - 2026年1月初）

**起源**：项目最初以 "Clawd" 命名，后发展为 "Clawdbot"。

**命名由来**：创始人 Peter Steinberger 分享说："Clawd 诞生于2025年11月，是 'Claude' 与 'claw（爪子）' 的有趣结合。感觉很完美，直到 Anthropic 的法律团队礼貌地要求我们重新考虑。"

**更名原因**：Anthropic 公司（Claude AI 的开发者）的法律部门提出商标问题，要求更改名称。

### 2. Moltbot（2026年1月 - 2026年1月30日）

**命名由来**：Steinberger 解释道："Moltbot 是在凌晨5点的 Discord 社区混乱头脑风暴中选出的。蜕皮（Molting）代表成长，龙虾蜕壳才能长大。这很有意义，但读起来不太顺口。"

**问题**：
- 名称读起来不太顺口
- 加密货币骗子利用更名混乱发布假代币
- 社区出现混乱

### 3. OpenClaw（2026年1月30日至今）

**最终定名**：项目于2026年1月30日正式定名为 OpenClaw，在经历数周的快速增长和早期商标问题后，重新命名为一个更清晰、更具开源精神的名称。

**命名优势**：
- "Open" 明确表示开源性质
- "Claw" 保留了项目的龙虾吉祥物形象
- 避免与任何现有商标冲突

## 创始人与愿景

### Peter Steinberger (@steipete)

**背景**：
- 奥地利开发者
- PSPDFKit 公司创始人，后将公司出售给 Insight Partners
- 自称"退休后回来折腾 AI"

**项目愿景**：
创建一个真正能够代表用户执行任务的自主软件代理，而不仅仅是一个对话式聊天机器人。OpenClaw 设计为可以在本地或私人服务器上部署，通过各种消息平台接受命令，并能够管理日历、发送消息、进行研究，以及在多个服务之间自动化工作流程。

**核心理念**：
- 数据隐私：运行在用户自己的设备上
- 完全控制：用户完全掌控数据和工作流
- 真正自主：不仅是聊天机器人，而是能执行任务的代理

## 项目特点

### 技术特点

1. **自主软件代理**：能够代表用户执行任务，而非仅仅对话
2. **本地部署**：可在本地或私人服务器上运行
3. **多平台支持**：通过 WhatsApp、Telegram、Signal、飞书等消息平台接受命令
4. **集成外部 AI**：支持多种 LLM 模型和 API
5. **自动化工作流**：管理日历、发送消息、进行研究、跨服务自动化

### 安全关注

OpenClaw 成为2026年初最受关注的开源 AI 代理之一，不仅因为它的功能强大，还因为它跨越了许多工具没有跨越的界限——它将大型语言模型与对操作系统、文件、凭证和消息平台的直接自主访问相结合。

**安全建议**：
- 由于具有系统级权限，建议在独立的服务器上部署
- 避免在生产环境或重要数据的机器上运行
- 关注官方安全更新和修复

## 当前路线图

项目路线图的优先级：

1. **安全性**：作为最高优先级
2. **网关可靠性**：确保稳定运行
3. **模型支持**：添加更多模型和提供商支持
4. **社区建设**：
   - 添加维护者
   - 建立处理大量 Pull Requests 和 Issues 的流程
   - 计划适当支付维护者报酬（可能是全职）
